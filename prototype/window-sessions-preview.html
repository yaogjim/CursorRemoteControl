CursorRemote Web UI 原型 · 窗口区分 + 会话列表
静态预览，未接入任何逻辑。仅调整 UI 结构与视觉层级。
设计决策与实现约束：
  • 信息层级：现在窗口条和会话条视觉同形，单窗口时窗口条隐藏。原型合并成一行上下文条（窗口蓝框标签 + 窗口计数 + 当前会话），永远可见，节省 ~36px 高度。
  • 会话列表：现在是横向胶囊条（.tab-item），没有列表也没有排序。原型改成抽屉里的纵向列表。排序方案：直接使用 state.chatTabs 数组顺序（假设 Cursor 已按最新在上排列）。
  • 数据约束：ChatTab 无时间戳（只有 composerId/title/isActive/status/selectorPath），所以直接用数组顺序。"just now / 12m ago" 这类相对时间是原型演示，实际实现可选（需客户端记录 firstSeenAt 并持久化到 localStorage）。
  • 非当前窗口：服务端 chatTabs 只对应当前窗口。非当前窗口卡片折叠显示提示，点击切窗后抽屉自动关闭，回到主界面等待 state:patch 更新会话列表。
  • New Chat 按钮：只在上下文条右侧保留一个，对当前窗口生效。非当前窗口不显示"New chat in this window"按钮，简化交互。
